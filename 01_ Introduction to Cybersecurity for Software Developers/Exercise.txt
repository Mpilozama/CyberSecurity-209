## CASE STUDY BACKGROUND

**What is Base44?**

Base44 is an AI-powered software development platform that allows users to build applications.

**What happened?**

In July 2025, cybersecurity researchers at Wiz discovered a vulnerability in Base44's API.

The vulnerability involved the user registration process for private applications. Someone who knew a publicly visible application ID could potentially register an account and access an application without proper authorisation.

The vulnerability was reported and subsequently fixed.
